# The-Role-of-Randomness-in-Cryptographic-Security
Empirical security and performance evaluation of CSPRNGs (ChaCha20, Secrets) vs. Non-Crypto PRNGs (LCG, Mersenne Twister). Evaluated across 10M-bit streams using NIST SP 800-22, Shannon Entropy, Chi-Square uniformity, and Pearson linear correlation.
